【这个软件是做什么的】
  把卫星影像丢进去，它会自动找出地表变化（新增违建、灾后损毁等），
  给出无人机航摄任务建议，调用三维高斯泼溅重建出三维模型，
  最后生成一份结构化的分析报告。遥感筛查 + 三维验证，一条龙。

----------------------------------------------------------------
【怎么用】 全图形界面，不用敲命令
----------------------------------------------------------------

  第 1 步：双击  一键启动.bat
           它会**先检测这台电脑的环境**：
             · 环境齐备    -> 直接打开图形界面（约 0.3 秒）
             · 环境不完整  -> 自动帮你装依赖（约 2 GB，10~30 分钟），
                              装完自动继续启动，不用你再操作一次
             · 没装 Python -> 会提示你去装 Python 3.9+
           所以正常情况下你只需要双击这一个文件。

  想单独看看这台电脑的环境到底怎么样，双击  检测环境.bat ，
  它会逐项列出 Python 版本、每个依赖是否就绪、模型权重、
  显存/内存/磁盘，并给出结论和下一步建议。

  只想装环境、不启动界面，双击  安装依赖.bat 。

  第 2 步：在界面里点「生成演示数据」→ 再依次点三个解译按钮
           （语义分割 / 目标检测 / 变化检测）→ 最后点
           「生成分析报告」。全套结果会出现在 outputs 目录下。

  想跳过界面直接看效果，可以双击  演示模式.bat ，
  它会无人值守跑一遍完整流程。

----------------------------------------------------------------
【四个 bat 分别干什么】
----------------------------------------------------------------
  一键启动.bat   先检测环境，缺就自动装，然后开图形界面   <- 平时只用这个
  检测环境.bat   只做体检，逐项报告并给建议（不改动任何文件）
  安装依赖.bat   只装依赖（环境已好时重跑也安全，会自动跳过）
  演示模式.bat   检测环境后无人值守跑一遍完整流程出成果

----------------------------------------------------------------
【电脑要什么配置】
----------------------------------------------------------------
  * Windows 10/11 64 位
  * Python 3.9 或更高（安装时务必勾选 "Add Python to PATH"）
  * 内存 8 GB 以上，硬盘预留 5 GB
  * 想跑三维重建（可选）：NVIDIA 显卡 + 至少 6 GB 显存
      三维部分另有一套独立环境，详见 3DGS后端说明.md
      没有显卡也能用，只是三维重建会退回内置的简化实现

----------------------------------------------------------------
【目录里都有什么】
----------------------------------------------------------------
  run_app.py            程序入口（也可以命令行调用，见下）
  aerosky\              系统源码（解译模型 / 三维后端适配 / 配准 / 报告）
  tools\                命令行工具（重建、SfM、下载数据集、环境检查）
  weights\              预训练权重（已带，离线可用）
  configs\default.yaml  配置文件（改这里可以调参数）
  tests\                自动化测试（12 个用例）
  示例成果\             已经跑好的一套成果，可以先看这个了解效果
  文档：README.md（系统说明）、3DGS后端说明.md（三维部分）、
        项目交付说明.md（交付清单与实测数据）

----------------------------------------------------------------
【命令行速查】 在软件目录下打开终端
----------------------------------------------------------------
  环境自检        .venv\Scripts\python run_app.py --check
  图形界面        .venv\Scripts\python run_app.py
  端到端演示      .venv\Scripts\python run_app.py --demo
  跑测试          .venv\Scripts\python tests\test_aerosky.py
  三维重建        .venv\Scripts\python tools\run_3dgs.py --list
  看有哪些后端    .venv\Scripts\python tools\run_3dgs.py --list
  下载多视角影像  .venv\Scripts\python tools\download_3d_data.py --list

----------------------------------------------------------------
【遇到问题】
----------------------------------------------------------------
  * 双击没反应 / 一闪而过：说明没装 Python，或装的时候没勾 PATH。
  * 装依赖时卡住或报网络错误：重跑一次 安装依赖.bat 即可，
    pip 支持断点续传；也可以在 configs 之外改用其它 pip 镜像。
  * 界面提示找不到某个模型权重：weights\ 目录不完整，
    重新解压整个压缩包，不要只拷一部分文件。
  * 三维重建报错：见 3DGS后端说明.md，需要 NVIDIA 显卡和单独的环境。
